# Game Engine Adapters

JagX AI is engine-independent.

Adapters translate general game concepts into engine-specific projects. Each adapter should support project discovery, scene/project representation, assets, code targets, build/test commands, logs, error parsing and repair hooks.

Targets:
- Godot 4.x — first adapter
- Unreal Engine — planned
- Unity — planned
- Generic/custom engines — planned
- WebGL/WebGPU game workflows — planned

The goal is complete playable project generation, not merely code snippets.
