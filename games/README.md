# JagX Game AI

Godot 4.x is the first game-engine target.

The game agent will progressively learn to:
1. Parse a game specification.
2. Create a Godot project and scene tree.
3. Generate GDScript/C#.
4. Build 3D player controllers and cameras.
5. Implement FPS weapons, health, damage, enemies and navigation.
6. Generate UI and game rules.
7. Run headless builds/tests.
8. Read errors and repair the project.
9. Add multiplayer as a later capability.

The goal is measurable, repeatable generation of playable projects—not a claim that the starter model already has frontier game intelligence.
