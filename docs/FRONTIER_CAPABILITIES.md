# JagX AI Frontier Capability Targets

JagX AI aims for broad capability rather than copying one competitor.

## Intelligence
- General knowledge and QA
- Multi-step reasoning and mathematics
- Long-context understanding
- Planning, self-critique and verification
- Uncertainty awareness

## Engineering
- Repository-scale coding
- Full-stack applications
- Real-time distributed applications
- API/database/authentication design
- Debugging and refactoring
- Build/test/fix loops
- Cross-platform software

## Creative and interactive
- UI/UX
- Advanced web animation
- WebGL/WebGPU
- 2D/3D and realistic games
- Godot, Unreal, Unity and generic engines

## Agent
- Tool calling
- Files and sandboxed terminal
- Browser/network tools
- Persistent project state
- Parallel subtasks
- Long-running jobs
- Checkpoint/recovery
- Verification before completion

## Research and security
- Retrieval and source-aware synthesis
- Experiment planning
- Isolated code execution
- Benchmark-driven evaluation
- Secure coding, threat modeling, vulnerability detection and remediation

## Multimodal direction
Interfaces will support future image, audio, video and structured-data understanding without redesigning the core agent.

The objective is independent implementation of comparable capabilities, with claims of superiority made only when benchmarks demonstrate them.
