# JagX Game Agent

JagX is being extended from game generation into game understanding, play-testing and autonomous play for environments where automation is permitted.

## Loop

`observe -> perceive -> plan -> permission check -> act -> observe -> adapt`

The agent can target goals such as finishing a level, practicing a mechanic, testing a generated game, or maximizing a score where the game rules permit automation.

## Architecture

- `agent/game_agent.py` — high-level game task orchestration.
- `agent/game_perception.py` — screen/frame to structured game state.
- `agent/game_policy.py` — policy contracts and a safe fallback policy.
- `agent/computer_control.py` — user-authorized input boundary.

A real vision model and game policy can be plugged in without changing the orchestration layer.

## Boundaries

Game control must use normal, authorized input mechanisms. JagX must not bypass anti-cheat, DRM, authentication, access controls, or other protections. Competitive games may prohibit automation even when the user owns the computer; the host should enforce those rules.

## Next training targets

1. UI and HUD detection.
2. Character/object localization.
3. Temporal state tracking.
4. Goal and reward estimation.
5. Action prediction.
6. Offline/simulation reinforcement learning.
7. Play-test regression datasets for games generated by JagX.
