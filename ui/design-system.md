# JagX AI Design System

## Direction

Premium AI workspace: dark-first, spacious, calm, technical, and content-focused.

## Color roles

- Background: near-black charcoal
- Surface: elevated charcoal panels
- Text: high-contrast neutral
- Muted text: subdued neutral
- Accent: one restrained electric accent used for focus and primary actions
- Status: semantic success/warning/error roles

## Layout

- Mobile-first responsive layout
- Desktop workspace uses persistent navigation and resizable panels
- Chat content stays readable with a constrained measure
- IDE uses a three-zone layout: explorer, editor, assistant/terminal

## Interaction

- Fast transitions, no excessive animation
- Clear loading and streaming states
- Keyboard shortcuts on desktop
- Touch-friendly controls on mobile
- Destructive actions require confirmation
