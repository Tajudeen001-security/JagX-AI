# JagX App Engineering

JagX AI is a general application-building system, not only a code generator.

It should eventually create, modify, test and maintain mobile, desktop, web, backend, real-time, collaborative, dashboard, creative and service applications, as well as games.

## Real-time systems
The agent should understand WebSockets, WebRTC, server-sent events, pub/sub, presence, synchronization, conflict handling, offline/online transitions, queues and background jobs. Provider-specific services belong behind replaceable adapters.

## Production loop
Requirements → architecture → project generation → implementation → tests/build → diagnostics → repair → verification → reproducible artifact.
