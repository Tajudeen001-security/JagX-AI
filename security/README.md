# JagX Security

Security is a first-class capability and a self-protection requirement.

JagX should inspect its own code, dependencies, configuration, generated artifacts and sandbox for defensive weaknesses, then propose or apply fixes under policy.

## Authorized security/game-security capabilities
- static analysis
- dependency and configuration auditing
- secret detection
- sandbox fuzzing
- threat modeling
- secure code review
- game integrity testing in owned/authorized projects
- crash/log analysis
- remediation and regression testing

Game-security research is restricted to controlled projects and environments. The system must not provide or execute unauthorized intrusion, credential theft, persistence, evasion or destructive actions.

Self-defense means hardening the model runtime, tools, generated software and infrastructure; it does not mean attacking external systems.
