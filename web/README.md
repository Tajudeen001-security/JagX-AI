# JagX Web Engineering

JagX AI should be capable of building production-oriented web applications, not only static pages.

Target stack-agnostic abilities:
- architecture selection
- frontend components
- backend APIs
- databases
- authentication
- real-time communication
- tests
- accessibility
- responsive design
- animation
- WebGL/WebGPU
- build and deployment validation

The agent should inspect an existing repository before modifying it and run tests/builds after changes.
